# Hilos de Resiliencia

Plataforma pedagógica sobre la memoria del conflicto armado en Colombia: territorios, diálogo crítico, cuidado socioemocional y pactos de no repetición.

## Qué es

Es una página web autocontenida (un solo archivo `index.html` con su CSS y su JavaScript incrustados) que funciona como material educativo interactivo: mapa del país por departamentos, relatos por territorio y actividades de trabajo en el aula.

## Requisitos

Ninguno. Solo un navegador web moderno.

## Cómo se ejecuta

**En local:** abre `index.html` con doble clic o desde el navegador:

```bash
xdg-open index.html      # Linux
open index.html          # macOS
start index.html         # Windows
```

**En línea:** si GitHub Pages está activado, la página se sirve desde la raíz del repositorio (`index.html`).

## Notas

- La tipografía se carga desde Google Fonts, así que el primer render necesita conexión a internet; el resto del contenido funciona sin conexión.
- La interfaz respeta el tema claro/oscuro del sistema.
